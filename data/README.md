# Procyon Bending Angle Data Derived from SOHIP V3Cam

This directory contains the released dataset:

`procyon_V3Cam_f=20000_d=0088x0096_b=01_e=000000800us_t=1371332732208ms.csv`

## Release Information

- Dataset title: Procyon Bending Angle Data Derived from SOHIP V3Cam
- LLNL dataset identifier: LLNL-DATA-2019578
- Control/publication number: CP 2026-180
- Distribution type: Unlimited/Notice 1
- Authors: Lance M. Simms, Cesar Laguna, and Dana L. McGuffin

## File Description

The CSV file contains Procyon bending angle data derived from SOHIP V3Cam.
It has one header row and 20,000 data rows.

Columns:

- `GPSTime`: GPS time in seconds.
- `ISSLat(deg)`: International Space Station latitude in degrees.
- `ISSLon(deg)`: International Space Station longitude in degrees.
- `ISSAlt(m)`: International Space Station altitude in meters.
- `RadiusLocalCurv(m)`: Local radius of curvature in meters.
- `VectorPerigeeLat(deg)`: Perigee vector latitude in degrees.
- `VectorPerigeeLon(deg)`: Perigee vector longitude in degrees.
- `VectorPerigeeAlt(m)`: Perigee vector altitude in meters.
- `beta(rad)`: Bending angle in radians.
